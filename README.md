# Gary Portfolio

個人作品集網站，展示後端專案、技術文章與經歷。

- [Live demo](https://portfolio.garydemo.com/)

![Portfolio Banner](public/images/readme-banner.jpg)

## Tech Stack

- [Nuxt 3](https://nuxt.com) — 全端框架
- [Nuxt Content v3](https://content.nuxt.com) — 內容管理（Markdown / YAML）
- [Nuxt UI](https://ui.nuxt.com) — UI 元件庫

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
